# Security policy

Haunt has not received an independent security audit. Treat deployments as
self-hosted services that require careful TLS, backup, update, and administrator
practices.

## Supported versions

Security fixes target the newest coordinated release and the current `main`
branch. Older releases may require an upgrade before receiving a fix.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** feature for the affected Haunt repository.
If that feature is unavailable, contact a repository owner privately. Do not open
a public issue or include secrets, private user data, working exploits, or
unredacted deployment details in a public channel.

Include the affected repository and commit, impact, prerequisites, reproduction
steps, and any suggested mitigation. Reports are acknowledged and prioritized
according to impact; the project does not currently promise a response SLA or
bug bounty.

For a problem spanning components, report it against the
[Haunt hub](https://github.com/example-git/haunt/security/advisories/new).
